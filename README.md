# Traffic Light Controller (Verilog)

## Overview

This project implements a Moore Finite State Machine (FSM) based traffic light controller in Verilog HDL.

The controller manages two intersecting roads using four traffic states while ensuring safe transitions between green, yellow, and red lights.

---

## Features

- Moore FSM
- Synchronous Design
- Active High Reset
- Parameterized Timer
- Modular RTL
- Verilog Testbench
- Waveform Verification
